# 🎵 Music Player Website

A stylish and lightweight music player built with **HTML**, **CSS**, and **JavaScript**. This project aims to provide a clean, functional audio player for web users with interactive UI elements and modern features.

## ✨ Features

- 🎧 **Play, Pause, Next, Previous**
- 🕒 **Real-time seekable progress bar**
- 🔊 **Volume control with mute/unmute**
- 🔁 **Loop and Shuffle functionality**
- 📀 **Track info with title, artist, and album cover**
- 💾 **Remembers your last played track (using `localStorage`)**
- 📱 **Responsive design – works on mobile, tablet, desktop**
- 🧠 **No frameworks – built with vanilla JavaScript**
